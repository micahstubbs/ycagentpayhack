# Project Description (One Paragraph)

Durin Invoice-Backed Lending Marketplace for AI Agents solves a fundamental problem in autonomous commerce: AI agents running businesses face the same cash flow challenges as humans—they have outstanding invoices (receivables) but need immediate liquidity to operate. Our solution enables a Business Agent with a $1,000 invoice NFT (due in 30 days) to get paid early by borrowing $800 from a Lender Agent using the invoice as blockchain-secured collateral, similar to traditional trade finance factoring but fully autonomous. The system bridges three payment layers: Stripe Connect provides the fiat on-ramp so humans can fund agents with credit cards, Locus enables fast agent-to-agent USDC payments (proven working: Lender autonomously paid Credit Analyst $20 for creditworthiness analysis with zero human intervention), and Base smart contracts provide trustless escrow for the invoice-backed loan settlement. Built with Anthropic's Claude Sonnet 4.5, this infrastructure layer enables AI agents to participate in the economy—getting funded, transacting with each other, and executing complex financial workflows autonomously.
